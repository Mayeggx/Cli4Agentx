---

## 文件约定

日记存放在话题目录的 `journal/` 子目录，按年月分文件夹，每天一个文件：

```
journal/
└── 2026-03/
    ├── 2026-03-17.md
    └── 2026-03-18.md
```

## 写入当日笔记

### 1. 获取今天日期

```
time
```

### 2. 检查今日文件是否已存在

```
ls journal/2026-03
```

### 3. 追加内容（保留历史）

如果文件已存在，先读取再追加：

```
cat journal/2026-03/2026-03-17.md
```

然后写入更新后的完整内容：

```
write journal/2026-03/2026-03-17.md
stdin: <完整文件内容，包含新增条目>
```

新条目格式建议：

```markdown
## 15:30

完成了 xxx 功能的开发，主要解决了 yyy 问题。

下一步：zzz
```

### 4. 如果文件不存在，直接创建

```
mkdir journal/2026-03
write journal/2026-03/2026-03-17.md
stdin: # 2026-03-17\n\n## <时间>\n\n<内容>
```

## 将重要内容存入记忆

对于重要决策、关键发现、需要长期记住的事项，额外存入 Facts：

```
memory store <精炼后的一句话事实>
```

这样未来可以通过 `memory search` 跨话题找到。

## 回顾历史笔记

```
# 看某一天的记录
cat journal/2026-03/2026-03-17.md

# 搜索包含关键词的日记
cat journal/2026-03/2026-03-17.md | grep <关键词>

# 查看记忆中的相关事实
memory search <关键词>

# 查看最近的对话摘要
memory recent 10
```

## 月度汇总

月末可以请 Agent 汇总当月所有日记：

```
ls journal/2026-03
cat journal/2026-03/2026-03-01.md
cat journal/2026-03/2026-03-02.md
...（依次读取）
```

读取完毕后写一份月度总结到 `journal/2026-03/summary.md`。
